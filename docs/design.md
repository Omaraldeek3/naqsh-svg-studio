# Naqsh — SVG library and studio

Approved scope: Arabic-first library and editor for designers/developers, with all asset categories, original editable vectors, search, customization, composition and export. The user authorized continuous implementation and review after completion on 2026-09-30; do not insert approval gates.

Standalone project in `svg-studio`; preserve the portfolio and other projects. Next.js 16.3.5, React 19.3.0, TypeScript, locally hosted Tajawal. No external accounts or paid APIs. Static export supports GitHub Pages or any static hosting.

Visual direction: warm off-white editorial workspace, forest green controls, original vivid vector previews, generous Arabic typography, persistent compact sidebar. Catalog is the first-screen task, not a marketing landing page. Responsive Arabic RTL with isolated Latin metadata.

Library: 96 original procedural designs, eight authored geometric/compositional recipes in each of twelve categories: backgrounds, patterns, illustrations, icons, dividers, interface states, badges, charts, frames, geometric marks, animated graphics and scenes. Items carry Arabic/English search terms, style, palette, authorship and CC0 asset license. Distinct designs, not claims of thousands of handcrafted assets. Render deterministic SVG with safe generated markup.

Flows: search/filter/sort; favorites; coherent category packs; customize primary/accent/background, density, stroke, dimensions, animation, transparency; preview SVG in light/dark/checkerboard and UI context; SVG/PNG/React/CSS exports; import safe local SVG; composition with layer move, resize, rotation, opacity, duplicate, ordering, deletion, undo/redo; project JSON import/export; drafts and favorites persist locally. Offline browser data, with graceful storage failure handling.

Verification: catalog uniqueness and valid markup; sanitizer rejects executable/external content; export utilities and ZIP integrity; Playwright exercises search, favorites/reload, customizer, downloads, composition and mobile; typecheck and production static build; inspect desktop/mobile screenshots. Show preview and provide run/contribution/license docs.
