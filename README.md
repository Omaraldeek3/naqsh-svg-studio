# نقش — Naqsh SVG Studio

[المستودع على GitHub](https://github.com/Omaraldeek3/naqsh-svg-studio)

مكتبة واستوديو SVG مفتوح المصدر للمصمّمين والمبرمجين، يبدأ بالزخارف العربية والإسلامية والنباتية.
**384 تكوينًا زخرفيًا** في ستة أقسام: هندسية إسلامية، أرابيسك عربي، زخارف نباتية،
وردات وميداليات، إطارات مزخرفة، وفواصل وحواف. يتضمن ذلك 48 شبكة هندسية متصلة
و48 تكوينًا لأشرطة هندسية بخطوط متوازية، مستوحاة من النجوم والمضلعات والأشرطة
الزخرفية. الاختلافات في الهندسة والتكوين؛ لا تُحتسب إعادة التلوين كتصميم جديد.

تضم المكتبة كاملة **14,108 SVG**: 480 تصميمًا أصليًا من نقش (384 زخرفة و96 أصلًا سابقًا)،
و6,198 أيقونة Tabler، و7,430 أيقونة Material Design Icons في قسم «أصول الواجهات» الثانوي.
تخصيص وتركيب وتصدير داخل المتصفح دون حساب أو خدمات مدفوعة.

العدد يمثل ملفات فعلية بعد حذف تكرارات هندسية واستبعاد العناصر غير المدعومة.
لا يتضمن مجرد تغييرات في اللون ولا الأسماء المستعارة. التصفّح يعرض 24 أصلًا
فقط في كل صفحة، مع القفز إلى أي صفحة وتصفية المصدر والبحث بالعربية والإنجليزية.
المعاينات الجديدة تُحمّل عند عرضها من الملفات المحلية؛ لا تحتاج اتصالًا بخدمة خارجية.

## التشغيل

يتطلب Node.js 24 أو أحدث وnpm.

```sh
git clone https://github.com/Omaraldeek3/naqsh-svg-studio.git
cd naqsh-svg-studio
npm ci
npm run dev
```

افتح http://127.0.0.1:3015. المشروع مستقل ويحتوي الكود وملفات SVG والتراخيص
وحزم التنزيل المحلية؛ لا يحتاج ملفات مشروع آخر.

## ما يمكنك فعله

- البحث بالعربية والإنجليزية، التصفية بالأسلوب والقسم، وترتيب الأصول.
- تصفّح الزخارف افتراضيًا، أو الانتقال إلى أصول الواجهات أو المكتبة كاملة.
- تنزيل الزخارف الـ384 كحزمة مستقلة، أو كل قسم في ملف ZIP.
- تنزيل وحدة التكرار للشبكات والأشرطة الجديدة كملف SVG مستقل؛ تصدير CSS
  يستخدم البلاطة مع تكرارها وأبعادها الصحيحة.
- حفظ المفضلة وتطبيق ألوان هوية موحّدة على المكتبة.
- تخصيص الألوان والأبعاد والشفافية والسماكة وكثافة الأنماط والحركة.
- معاينة الرسم في واجهة نموذجية أو على خلفية فاتحة/داكنة/شفافة.
- تنزيل SVG وPNG أو كود React وCSS، وتنزيل مجموعة كاملة كملف ZIP.
- تركيب مشهد بالطبقات، السحب والتحريك بالأسهم، تغيير الحجم، الدوران،
  الشفافية، ترتيب الطبقات، إخفائها وتكرارها، والتراجع والإعادة.
- استيراد SVG آمن، وحفظ/فتح مشروع JSON، وتصدير المشهد النهائي.

المفضلة والهوية ومسودة الاستوديو محلية لهذا المتصفح. صدّر JSON لنسخة
احتياطية أو للنقل بين الأجهزة. لا توجد مزامنة سحابية أو حسابات مستخدمين.
الاستيراد يرفض السكربتات والأنماط الخارجية والصور والروابط الخارجية؛
الأصول التي تعتمد عليها تحتاج تبسيطًا في برنامج الرسم قبل استيرادها.
المحاكاة داخل الواجهة هي معاينة للرسم، وليست تحويلًا كاملًا للتصميم إلى موقع.

## التحقق والبناء

```sh
npm test
npm run typecheck
npm run test:e2e
npm run export:assets
npm run build
npm start
```

اختبارات المتصفح تستخدم Microsoft Edge المثبّت. على بيئة أخرى غيّر
`channel` في `playwright.config.ts` وثبّت Chromium عبر `npx playwright install chromium`.
الناتج الثابت في `out/` ويمكن نشره على أي استضافة ملفات ثابتة.
لموقع GitHub Pages داخل مسار مستودع، اضبط `NEXT_PUBLIC_BASE_PATH=/repository-name`
قبل البناء. `npm start` مخصّص لمعاينة بناء دون base path على المنفذ 3015.

## بنية المشروع

- `src/lib/catalog.ts`: بيانات الأصول، الأقسام، اللوحات والبحث.
- `src/lib/ornament-data.ts` و`ornaments.ts`: عائلات الزخارف وتكويناتها المتجهية.
- `src/lib/geometric-data.ts` و`geometric-ornaments.ts`: الشبكات المتصلة والأشرطة
  ووحدات التكرار وحدود المضلعات المتوازية.
- `src/lib/svg.ts`: وصفات الرسم الأصلية وتخصيص SVG.
- `src/lib/project.ts`: الطبقات والتحقق من المشاريع وتصدير التكوين.
- `src/lib/sanitize.ts`: الاستيراد الآمن وعزل معرّفات SVG بين الطبقات.
- `src/lib/export.ts`: PNG، React، CSS، الحافظة وZIP دون مكتبة إضافية.
- `src/components`: المكتبة والمخصّص والاستوديو.
- `public/assets`: الأصول المصدّرة وملف البيانات الوصفية.
- `tests`: تحقق البيانات والتصدير وتجارب المستخدم.

ابدأ من [دليل المساهمة](public/contributing.txt). أرفق معاينة وتوثيقًا لكل أصل.
الأصول الأصلية تحت [CC0 1.0](ASSET-LICENSE.md)، والكود تحت [MIT](LICENSE).
أيقونات Tabler تحت MIT، وMaterial Design Icons تحت Apache-2.0. النصوص الكاملة
والمصدر وتجزئات البيانات موجودة في `public/licenses/`، وتُرفق مع المجموعات

ولا يحدث أثناء تشغيل المستخدم للموقع. `npm run export:assets` يصدّر تصاميم نقش
ويحدّث بيان جميع الأصول. اختلاف الصيغ والإصدارات قد يؤثر على عرض الحركة عند فتحها في
برامج الرسم؛ نسخة PNG ثابتة وملف SVG قابل للتعديل.
